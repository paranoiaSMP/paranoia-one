# PARANOÏA ONE — PRODUCT VISION

**Publisher:** Paranoïa Studio  
**Product:** Paranoïa One  
**Version:** 1.0  
**Status:** In Development

## 1. Overview

Paranoïa One is a cross-platform workspace application designed to bring personal organization and professional collaboration together in one unified product.

The application is divided into two independent environments: Personal and Pro.

## 2. Platforms

Paranoïa One will be available on three platforms:

- Web: accessible through a browser.
- Phone: native mobile experience for Android and iOS.
- Desktop: desktop application for Windows, macOS and Linux.

## 3. Personal Environment

The Personal environment is designed for individual organization.

Planned features:
- Personal dashboard
- Notes
- Tasks
- Calendar
- Habits
- Goals
- Personal projects
- Focus tools
- Personal resources

Personal data is private by default.

## 4. Pro Environment

The Pro environment is designed for teams and collaborative work.

Planned features:
- Workspaces
- Members
- Roles and permissions
- Projects
- Tasks and assignments
- Kanban boards
- Comments
- Announcements
- Activity feed
- Notifications
- Team settings

## 5. Core Principles

- Privacy by default
- Clear separation between Personal and Pro
- Consistent experience across platforms
- Secure data access
- Reliable synchronization
- Modular and maintainable architecture
- Scalability

## 6. Technical Direction

- Backend: Rust
- Backend framework: Axum
- Database: PostgreSQL
- SQL access: SQLx
- Web: React + TypeScript
- Desktop: Tauri 2 + React
- Phone: React Native
- Local storage: SQLite
- API: REST

## 7. Product Objective

Build a reliable, secure and maintainable productivity platform that combines personal organization and professional collaboration without compromising privacy.
